# Программа A — изменение цвета символов

Программа для Linux выводит текст в терминале и меняет его цвет без нажатия Enter.
Для сборки нужен компилятор C++17 и CMake.

## Сборка и запуск

```bash
cmake -S . -B build
cmake --build build
./build/program_a --text Hello --color green --size 3
```

Параметры можно опустить: `--text` по умолчанию равен `Hello`, `--color` —
`green`, `--size` — `1`. Размер означает число повторений текста в одной строке;
повторения разделяются пробелами. Цвета: `red`, `green`, `blue`.
Программу нужно запускать в интерактивном терминале.

## Управление

| Клавиша | Действие |
| --- | --- |
| `r` | Красный |
| `g` | Зелёный |
| `b` | Синий |
| `+` | Следующий цвет: красный → зелёный → синий → красный |
| `q` | Выход |

Команды также можно посылать в `/tmp/program_a_fifo`, по одной на строку:

```bash
printf 'key=r\nkey=+\nkey=b\ncmd=color:blue\n' > /tmp/program_a_fifo
```

Команда `key=q` завершает программу. Неизвестные клавиши и некорректные
команды FIFO не меняют цвет.

События записываются с местным временем в `program_a.log` в текущем каталоге.
Файл дополняется при каждом запуске. Команды `key=` из FIFO и клавиши терминала
имеют одинаковый формат записи. Созданный программой FIFO удаляется при выходе;
если он существовал до запуска, программа его оставляет.

## Программа B

После сборки запустите из каталога проекта:

    ./build/program_b

Меню позволяет ввести параметры A, открыть её в отдельном окне Ptyxis и
отправлять команды через FIFO. Программы program_a и program_b должны
находиться в одном каталоге; CMake собирает их вместе в build.
Для отдельного окна нужен установленный /usr/bin/ptyxis и графический сеанс.

Программа B принимает key=r, key=g, key=b, key=+, key=q и
cmd=color: с одним из перечисленных выше цветов. После отправки
команды меню остаётся доступным. Выход из B не завершает A.

## Программа C

Соберите все три программы по командам выше и запустите C в отдельном терминале:

    ./build/program_c

C ищет исполняемый файл A рядом с собой, проверяет процесс в /proc и читает
program_a.log из рабочего каталога A. При новой записи key=+ она отправляет
key=b через /tmp/program_a_fifo. Журнал C называется program_c.log и создаётся
в текущем каталоге самой C. Для выхода из C введите q и нажмите Enter.

Текущий журнал A записывает одинаковое key=+ для клавиатуры и FIFO. Поэтому C
реагирует на оба источника и не может определить, каким способом пришла команда.
При подключении к уже работающей A C узнаёт время запуска из журнала, но
обрабатывает только события, появившиеся после подключения.

# Лабораторная работа: программы A, B и C

Проект рассчитан на Linux. Программа A показывает цветной текст в терминале,
B предоставляет графическое окно для запуска A и отправки команд, а C
наблюдает за работой A и записывает события в журнал.

## Сборка

Понадобятся компилятор C++17, CMake, Qt 6 Widgets и терминал Ptyxis. Например,
в Ubuntu пакеты для сборки можно установить так:

```bash
sudo apt install build-essential cmake qt6-base-dev ptyxis
cmake -S . -B build
cmake --build build
```

Для запуска B и Ptyxis нужен графический сеанс. Исполняемые файлы трёх программ
должны находиться в одном каталоге; CMake помещает их в `build`.

## Программа A

A можно запустить напрямую в интерактивном терминале:

```bash
./build/program_a --text Hello --color green
```

Параметры необязательны: текст по умолчанию — `Hello`, цвет — `green`. Поддерживаются цвета `red`, `green`, `blue`.

| Клавиша | Действие |
| --- | --- |
| `r` | Красный |
| `g` | Зелёный |
| `b` | Синий |
| `q` | Выход |

Команды можно отправлять через `/tmp/program_a_fifo`, по одной на строку:

```bash
printf 'key=r\nkey=b\ncmd=color:blue\n' > /tmp/program_a_fifo
```

Команда `key=q` завершает A. Неизвестные клавиши и некорректные команды не
меняют цвет. События дописываются в `program_a.log` в рабочем каталоге A.
Созданный A FIFO удаляется при выходе; если FIFO существовал до запуска, A
его оставляет.

## Программа B

```bash
./build/program_b
```

В окне задайте текст и цвет и нажмите «Запустить A». A
откроется в отдельном окне `/usr/bin/ptyxis`. Кнопки «Красный», «Зелёный»
и «Синий» отправляют через FIFO команды `cmd=color:red`, `cmd=color:green` и
`cmd=color:blue`. Кнопка «Завершить A» отправляет `key=q`. B записывает
команду в FIFO, A читает её и меняет цвет или завершает работу.

Состояние и ошибки показываются в окне B. B не запускает вторую A, пока первая
работает или её окно открывается. Закрытие B не завершает A.

## Программа C

Запустите C в отдельном терминале:

```bash
./build/program_c
```

C ищет исполняемый файл A рядом с собой, проверяет процесс в `/proc` и читает
`program_a.log` из рабочего каталога A. События дописываются в `program_c.log`
в рабочем каталоге C. Для выхода введите `q` и нажмите Enter.

При подключении к уже работающей A C узнаёт время её запуска из журнала, но
обрабатывает только события, появившиеся после подключения. Записи клавиш с
клавиатуры и команд `key=` из FIFO имеют одинаковый формат.
